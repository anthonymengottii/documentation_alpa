## Instalação

<Note>
  Este SDK ainda não está publicado no npm. Instale diretamente pelo GitHub:
</Note>

```bash
npm install github:anthonymengottii/upay-nodejs-sdk
```

## Uso Rápido

```ts
import UpayClient from '@upay/upay-js';

const upay = new UpayClient({ apiKey: process.env.UPAY_API_KEY });
```

## Criar Link de Pagamento

```ts
const link = await upay.paymentLinks.create({
  title: 'Produto Premium',
  amountCents: 9900,
  description: 'Acesso vitalício',
});
```

## Criar Transação PIX

```ts
const tx = await upay.transactions.create({
  product: 'Curso Node.js',
  paymentMethod: 'PIX',
  amountCents: 19900,
  clientName: 'João Silva',
  clientEmail: 'joao@example.com',
  clientDocument: '12345678900',
});

console.log(tx.pixCopiaECola);
```

## Validação de Webhooks

```ts
app.post('/webhook', express.raw({ type: 'application/json' }), (req, res) => {
  const isValid = upay.verifyWebhookSignature(
    req.body,
    req.headers['x-webhook-signature'] as string,
    process.env.UPAY_WEBHOOK_SECRET!
  );

  if (!isValid) return res.status(401).json({ error: 'Assinatura inválida' });

  const event = JSON.parse(req.body.toString());
  res.json({ received: true });
});
```

## Tratamento de Erros

```ts
import { UpayError, UpayValidationError } from '@upay/upay-js';

try {
  const tx = await upay.transactions.create({ ... });
} catch (error) {
  if (error instanceof UpayValidationError) {
    console.error('Dados inválidos:', error.message);
  } else if (error instanceof UpayError) {
    console.error(`Erro ${error.statusCode}:`, error.message);
  }
}
```
