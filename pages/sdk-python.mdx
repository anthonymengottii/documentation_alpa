## Uso Rápido

```python
import os
from alpa import AlpaClient

alpa = AlpaClient(api_key=os.getenv('ALPA_API_KEY'))
```

## Criar Link de Pagamento

```python
link = alpa.payment_links.create({
    'title': 'Produto Premium',
    'amountCents': 9900,
    'description': 'Acesso vitalício',
```

## Validação de Webhooks

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/webhook', methods=['POST'])
def webhook():
    is_valid = alpa.verify_webhook_signature(
        payload=request.data,
        signature=request.headers.get('x-webhook-signature', ''),
        secret=os.getenv('ALPA_WEBHOOK_SECRET'),
    )

    if not is_valid:
        return jsonify(error='Assinatura inválida'), 401

    event = request.json
    return jsonify(received=True)
```

## Tratamento de Erros

```python
from alpa import AlpaValidationError, AlpaError

try:
    tx = alpa.transactions.create({ ... })
except AlpaValidationError as e:
    print('Dados inválidos:', e)
except AlpaError as e:
    print(f'Erro {e.status_code}:', e)
```
